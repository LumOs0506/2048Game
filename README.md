# 2048 Game

A simple implementation of the 2048 game using HTML, CSS, and JavaScript.

## Functionalities

*   **Game Board:** A 4x4 grid to play the game.
*   **Tiles:** Tiles with values that are powers of 2.
*   **Movement:** Use the arrow keys to move the tiles up, down, left, or right.
*   **Merging:** When two tiles with the same number touch, they merge into one tile with the sum of their values.
*   **Score:** The score is the sum of the values of the merged tiles.
*   **New Game:** A button to start a new game at any time.
*   **Game Over:** The game ends when the board is full and there are no more possible moves.

## How to Play

1.  Use the arrow keys to move the tiles.
2.  Tiles with the same number will merge into one.
3.  A new tile (either 2 or 4) will appear in a random empty spot after each move.
4.  The game is over when the board is full and no more moves can be made.
5.  The goal is to create a tile with the value 2048.
